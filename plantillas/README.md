# Plantillas

Esta carpeta centraliza las plantillas y documentos de referencia. Los archivos
originales de la aplicacion siguen en `documentos/app-live`.

## Notas de intervencion

- `notas-intervencion/nota-intervencion-asm-v10.html`: primera hoja independiente, Nota Intervencion ASM.
- `notas-intervencion/nota-intervencion-general-v10.html`: segunda hoja independiente, Nota Intervencion General.
- `notas-intervencion/nota-mantenimiento-asm-v10.html`: documento combinado original de dos hojas, conservado como referencia.
- `notas-intervencion/normal-report-template-activa.html`: copia de la plantilla que la aplicacion usa actualmente para la nota PDF.
- `notas-intervencion/general-intervention-report-activa.html`: copia del informe adicional configurado desde el check de generacion de informe.

## Informes tecnicos ASM

Estas plantillas son informes tecnicos de mantenimiento, no notas de intervencion:

- `informes-tecnicos-asm/asmse-report-template.html`
- `informes-tecnicos-asm/asmii-report-template.html`
- `informes-tecnicos-asm/asmiii-report-template.html`
- `informes-tecnicos-asm/asmiv-report-template.html`

## Referencias PDF

`referencias-pdf/` contiene los PDFs v10 cumplimentables y firmables usados como
referencia visual de las dos notas de intervencion.
